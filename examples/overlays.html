What is Synteq UI?

Synteq UI V2 is a viewport-locked, offline-first dashboard framework built on six hard rules. It provides a complete component library for operator dashboards and admin panels.

How do I get started?

Link to synteq-ui-v2.css and synteq-ui-v2.js in your HTML. Use the shell template from the documentation to create your first page.

Is it accessible?

Yes. All components target WCAG 2.2 Level AA with keyboard navigation, ARIA attributes, and reduced-motion support. Full validation requires manual testing with assistive technologies.

Can I customize the theme?

Absolutely. Override CSS custom properties (--v2-* tokens) in your own stylesheet. See the theme extension guide in DESIGN.md for details.
